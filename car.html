복사한 링크를 카톡 등으로 보내고, 상대방이 그 링크를 한 번만 열면 바로 같은 예약표를 보게 됩니다. (링크에 접속 정보가 들어 있으니 두 사람끼리만 공유하세요.)

지금은 이 기기에만 저장됩니다. Supabase에 연결하면 두 사람 폰에서 같은 예약표를 실시간으로 보게 됩니다.

Supabase 준비 방법 (처음 한 번만)
  1. supabase.com 에서 프로젝트를 만듭니다 (무료).
  2. Project Settings → API 에서 URL과 anon public key를 복사해 위에 넣습니다.
  3. SQL Editor 에 아래를 붙여넣고 실행합니다.
create table if not exists car_schedule (
  room text primary key,
  data jsonb not null,
  updated_at timestamptz default now()
);

alter table car_schedule enable row level security;

create policy "car schedule access"
  on car_schedule for all
  using (true) with check (true);

alter publication supabase_realtime
  add table car_schedule;
  1. 다시 이 화면에서 연결하기를 누르면 끝입니다.
